# BookBridge

BookBridge is a community book-sharing and exchange platform built using Python Flask, HTML, CSS, JavaScript, and SQLite.

## Features
- Browse and search books
- Donate and exchange books
- List second-hand books at affordable prices
- User registration and login
- Book listing and request management
- Admin panel

## Technology Stack
- Python
- Flask
- HTML, CSS, JavaScript
- SQLite

## Project Type
Individual College Community Engagement Project (CEP).

Developed as an educational project to encourage book sharing and make books more accessible to students and readers.
