# BookBridge

BookBridge is a community book-sharing and exchange platform developed as a college project.

## Features
- Browse and search books
- Donate books
- Exchange books
- List second-hand books at affordable prices
- User registration and login
- Book request management
- Admin panel

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## Project Objective
The main objective of BookBridge is to encourage book sharing, reuse old books, and make books more affordable for students and readers.

## Project Type
Individual Community Engagement Project (CEP).
